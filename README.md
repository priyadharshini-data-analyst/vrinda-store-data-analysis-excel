# Vrinda Store Data Analysis – Excel

## Project Overview

This project analyzes Vrinda Store's e-commerce sales data using Microsoft Excel to identify sales trends, customer demographics, order status, sales channels, and top-performing states.

The objective of this project is to transform raw sales data into meaningful business insights using Excel data analysis and visualization techniques.

---

## Business Objective

The analysis focuses on answering key business questions:

- What are the monthly sales and order trends?
- Which states generate the highest sales?
- How do sales compare between men and women?
- What is the distribution of order status?
- Which sales channels contribute the most orders?
- How does age and gender affect purchasing behavior?
- Which customer segments contribute significantly to sales?

## Analysis Performed

### 1. Monthly Order vs Sales Analysis

Analyzed monthly order volume and sales amount to identify sales trends throughout the year.

### 2. Men vs Women Analysis

Compared purchasing behavior and sales contribution between male and female customers.

### 3. Order Status Analysis

Analyzed different order statuses to understand the distribution of completed, cancelled, returned, and other orders.

### 4. Top 5 States Analysis

Identified the top five states based on sales amount.

### 5. Age & Gender Analysis

Analyzed customer purchasing patterns across age groups and gender.

### 6. Sales Channel Analysis

Compared different sales channels to identify the channels contributing to orders.
